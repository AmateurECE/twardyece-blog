I put these contents into
`/etc/pipewire/pipewire.conf.d/11-audio-technica-turntable.conf`:

```
context.objects = [
    { factory = adapter
        args = {
            factory.name           = api.alsa.pcm.source
            node.name              = "turntable-adc"
            node.description       = "Audio Technica AT-LP120XUSB"
            media.class            = "Audio/Source"
            api.alsa.path          = "hw:1"
            api.alsa.period-size   = 1024
            api.alsa.headroom      = 0
            api.alsa.disable-mmap  = false
            api.alsa.disable-batch = false
            audio.format           = "S16LE"
            audio.rate             = 48000
            audio.channels         = 2
            audio.position         = "FL,FR"
        }
    }
]
```

I mostly copied this from the upstream `pipewire.conf` file, which gives an
example of setting up a node from an ALSA device. The `factory.name` is given
as `api.alsa.pcm.source`, which is a magic value that creates a PCM source.
This is given together with the class `Audio/Source`, another magic value which
tells pipewire clients that this node sources audio. I decide the `node.name`
and `node.description` parameters, based on the hardware I'm connecting to. The
final piece is the `api.alsa.path` parameter, given as `hw:1`. This is derived
from the ALSA card ID:

```
root@rpi-ab-mutable-gadget:~# aplay -l
**** List of PLAYBACK Hardware Devices ****
card 0: Modius [Schiit Unison Modius], device 0: USB Audio [USB Audio]
  Subdevices: 1/1
  Subdevice #0: subdevice #0
card 1: CODEC [USB AUDIO  CODEC], device 0: USB Audio [USB Audio]
  Subdevices: 1/1
  Subdevice #0: subdevice #0
```

I can check that this node exists with `pw-cli ls Node`. The last step is to
link these nodes in the Pipewire graph, so that audio flows from source to
sink. This is done using `pw-link`. First, use it to get the node IDs:

```
root@rpi-ab-mutable-gadget:~# pw-link -o
...
turntable-adc:capture_FL
turntable-adc:capture_FR
...
bluez_output.AC_80_0A_F6_D9_6E.1:monitor_FL
bluez_output.AC_80_0A_F6_D9_6E.1:monitor_FR
```

The stuff before the colon are the `node.name` properties of graph nodes, taken
from the output of `pw-cli ls Node`. Create a link between the nodes:

```
pw-link turntable-adc bluez_output.AC_80_0A_F6_D9_6E.1
```

To control the volume, use `wpctl`. First get the ID of the node, as known by
Wireplumber:

```
root@rpi-ab-mutable-gadget:~# wpctl status
...
Audio
...
 ├─ Sinks:
 │  *   60. WH-1000XM5                          [vol: 0.20]
...
```

Then, set the volume:

```
wpctl set-volume 60 0.25
```
